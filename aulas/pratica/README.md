# Aulas práticas de blockchain

### Aula 8

Comando para criar o debug do chrome:

```bash
alias chrome-debug="/mnt/c/Program\ Files/Google/Chrome/Application/chrome.exe --remote-debugging-port=9222"
```

Agora execute o comando:

```bash
chrome-debug
```

#### Execução da blockchain
Execução do motor da blockchain:

```bash
    npx hardhat node
```

Através do package.json existe o comando:

```bash
    npm run chain
```

#### Execução do frontend

npm run frontend:dev
