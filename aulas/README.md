# Blockchain e Web 3.0 - Índice de Resumos de Aulas

Este diretório contém resumos estruturados e pedagógicos das aulas da disciplina **Blockchain e Web 3.0**, cobrindo desde os fundamentos teóricos de redes distribuídas até o desenvolvimento prático de contratos inteligentes em Solidity e integração frontend com `ethers.js`.

Os resumos contam com visão geral, objetivos de aprendizagem, conceitos-chave definidos, explicações estruturadas, analogias do mundo real, pontos críticos para exames e flashcards para revisão ativa de conteúdo.

## 🚀 Como Utilizar para Estudo

1. **Recuperação Ativa (*Active Recall*)**: Ao ler os resumos, utilize a seção **Questões de Autoavaliação (Estilo Flashcard)** para forçar o cérebro a recuperar os conceitos antes de clicar em **Ver Resposta**.
2. **Revisão Espaçada (*Spaced Repetition*)**: Planeje revisões periódicas das conclusões e pontos críticos listados na seção 5 de cada aula antes de exames ou codificações complexas.
3. **Conversão em PDF**: Este índice e os arquivos individuais de resumo foram formatados com quebras de parágrafos curtos e tópicos bem distribuídos para facilitar a renderização e impressão limpa de apostilas de estudo em PDF.
